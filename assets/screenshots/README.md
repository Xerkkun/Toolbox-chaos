# Official Screenshots

This directory is intended for storing official screenshots of the Fyskode Chaotic Systems Toolbox. These screenshots are used by the public website.

## Guidelines
- Keep images light (recommended size < 2 MB).
- Avoid saving local file paths or environment details in the image.
- Supported extensions: `.png`, `.jpg`, `.webp`.

## Suggested Names
- `main-interface.png`: Main application window showcasing layout and system selector.
- `attractor-3d.png`: 3D phase space plot rendering a chaotic attractor (e.g., Lorenz, Sprott).
- `bifurcation-diagram.png`: Bifurcation sweeper interface showing a parameter sweep diagram.
- `coexisting-attractors.png`: Plot showcasing multistability and coexisting phase paths.
- `sprott-explorer.png`: The Sprott explorer interface displaying found candidates.
