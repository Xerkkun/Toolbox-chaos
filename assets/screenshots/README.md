# Official Screenshots

This directory is intended for storing official screenshots of the Fyskode Chaotic Systems Toolbox. These screenshots are used by the public website.

## Guidelines
- Keep images light (recommended size < 2 MB).
- Avoid saving local file paths or environment details in the image.
- Supported extensions: `.png`, `.jpg`, `.webp`.

## Current Files

The public capture set uses the `gui_*.png` names in this directory: attractor
3D, phase portraits, time series, Welch PSD, Lyapunov, bifurcation, basin,
coexistence, method comparison, equilibria/eigenvalues, dictionary, custom
system, and Sprott Explorer. Documentation must link to those actual files and
must not advertise an absent generic `main-interface.png`.
