# Sprott-inspired Explorer assets

This public asset folder supports the Sprott-inspired Explorer in Chaos Toolbox.

The module is inspired by Julien C. Sprott and the book *Strange Attractors:
Creating Patterns in Chaos* (M&T Books, 1993). Chaos Toolbox is not an
official Sprott release and does not redistribute the historical software, disk
files, dictionaries, figures, or book text.

All code in this repository is an independent modern educational
reimplementation. It is intended for teaching, computational preservation, and
research prototyping.

Users may load locally downloaded references from the official Sprott pages
under their own terms. Those local files remain outside the public repository
and are indexed only from the user's selected folder.
