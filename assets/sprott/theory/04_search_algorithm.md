# 04 Search Algorithm

El ciclo de busqueda es experimental:

- generar o cargar un codigo;
- decodificar familia y coeficientes;
- simular con transitorio;
- descartar divergencia;
- descartar punto fijo o baja complejidad;
- conservar candidatos acotados;
- aplicar diagnosticos y evaluacion visual.

`candidate_chaotic` en Chaos Toolbox significa acotado y no colapsado bajo
filtros rapidos. No es una prueba formal de caos.
