# 06 Visual Language

El lenguaje visual inspirado por Sprott combina proyeccion, color y densidad:

- proyecciones `x-y`, `x-z`, `y-z`;
- color por tercera dimension;
- bandas por variable adicional;
- fondo negro o blanco;
- puntos pequenos y alpha bajo para alta densidad;
- 4D como proyeccion 2D + color + bandas.

Anaglifos, esfera y sombras quedan como extensiones naturales, pero la fase
actual prioriza render reproducible y exportacion local.
