# 07 Using Local Dictionaries

Puedes cargar `BOOKFIGS.DIC`, `SELECTED.DIC` o `SPECIAL.DIC` desde una descarga
local. La app solo lee el archivo desde tu disco y no lo copia al repositorio.

La tabla muestra linea, codigo, familia, dimension, orden, F, L y soporte. Usa
filtros para ver solo simulables, mapas 2D/3D/4D, flujos 3D/4D, familias
especiales, `L` positivo o `F` alto.

Si un codigo es de familia especial pendiente, se conserva como referencia local
pero no se simula en esta fase.
