# 09 Modern Extensions

La reimplementacion usa backend moderno y puede ofrecer opciones que no son una
traduccion del software historico: RK4, exportacion vectorial, estilos por
colormap, metadatos JSON y galeria local.

Extensiones futuras razonables incluyen espectro completo de Lyapunov, dimension
Kaplan-Yorke, test 0-1, homologia persistente, aceleracion GPU/Numba y busqueda
en worker thread para no bloquear la UI.
