# Cobertura del catálogo Wang (2021)

Este archivo distingue la cobertura documental del generador y la API ejecutable de Chaos Toolbox. Una ficha con ecuaciones o una búsqueda numérica de equilibrios no equivale a una implementación de simulación, cuencas o bifurcaciones.

| Cobertura | Cantidad | Alcance |
|---|---:|---|
| Fichas transcritas y procesadas por el generador | 42 | Ecuaciones, parámetros, referencias y búsqueda numérica finita de equilibrios |
| Identificadores ejecutables en `SYSTEM_REGISTRY` | 25 | Simulación según el contrato del registro actual |
| Fichas sólo de referencia | 17 | No están disponibles en el selector ni en la API de simulación del registro |
