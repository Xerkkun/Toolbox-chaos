# JOSS Reviewer Guide

This guide is designed to help JOSS reviewers inspect and evaluate **Fyskode Chaotic Systems Toolbox**.

## 1. Quick Start (Install from Source)

Ensure you have Python 3.10+ installed.

1. **Install dependencies:**
   ```powershell
   python -m pip install -r requirements.txt
   ```
2. **Run the application:**
   ```powershell
   python main.py
   ```

Helpers for starting on different shells:
- **Windows:** `.\run.ps1`
- **Linux:** `./run-linux.sh`
- **macOS:** `./run-macos.command`

## 2. Desktop Installer Verification (Windows)

The official release for Windows is distributed as a desktop installer (`.exe`).
1. Download the pre-built installer: `installer/chaos-toolbox-v0.1.0-windows-x64-setup.exe` (or from the latest GitHub releases).
2. Execute the installer. It will install the application to your local user directory.
3. Launch `Chaos Toolbox` via the desktop shortcut or Start Menu.
4. Verify updates, documentation access, and results directories through the `Ayuda` menu.

## 3. Building and Packaging Scaffolding

### Windows
To compile the standalone application and generate the installer:
1. Ensure Inno Setup 6 (`ISCC.exe`) is installed.
2. Run the build script:
   ```powershell
   .\scripts\build_windows.ps1
   ```
- Standalone executable folder: `dist/Chaos Toolbox/Chaos Toolbox.exe`
- Installer setup: `installer/chaos-toolbox-v0.1.0-windows-x64-setup.exe`

### macOS & Linux
The repository contains PyInstaller and platform shell packaging stubs:
- macOS build script: `./scripts/build_macos.sh`
- Linux build script: `./scripts/build_linux.sh`

*Note: While these scripts prepare the PyInstaller executables and application structures, final distribution packages (such as `.dmg` installers or AppImage binaries) require execution on their native platform hosts.*

## 4. Running the Test Suite

Run the comprehensive unit test suite using `pytest`:
```powershell
python -m pip install pytest
python -m pytest -v
```

On headless Linux environments (e.g., CI runners), you must disable the display requirement for PyQt6 by running tests in `offscreen` mode:
```bash
QT_QPA_PLATFORM=offscreen python -m pytest
```

You can also run specific verification scripts to check packaging metadata and JOSS compliance:
```powershell
python scripts\verify_joss_metadata.py
python scripts\verify_packaging.py
python scripts\verify_public_release_clean.py
```

## 5. Reviewing Reproducible Examples

To evaluate the capabilities of the toolbox, open the UI and follow these steps:

1. **Attractor Trajectories & Projections:**
   - Select a system (e.g., *Lorenz*) from the left panel.
   - Click `Cargar parámetros por defecto` (Load Defaults).
   - Press `Simular` to integrate. You can rotate the 3D phase portrait, inspect the time series tab, and view the equations.

2. **Lyapunov Exponent Estimation:**
   - With the system loaded, navigate to the `Diagnósticos` or `Exponentes de Lyapunov` panel.
   - Click `Calcular` to sweep integration trajectories and estimate the spectrum of Lyapunov exponents.

3. **Bifurcation Sweeps:**
   - Open the `Bifurcaciones` panel.
   - Select a parameter to sweep, set step resolutions, and run the calculation to generate the bifurcation diagram.

4. **Fast Fourier Transform (FFT):**
   - Click the `Espectro FFT` tab.
   - Run the simulation to analyze the frequency distribution of the trajectories and inspect chaotic broadband noise.

5. **Attraction Basins & Coexistence:**
   - Select a system supporting coexistence (e.g., custom multi-scroll or cataloged multistable models).
   - Click `Mapa de Cuencas` to project the initial condition grid showing different attractor destinations in distinct colors.

## 6. Verifying Non-Redistribution of Sprott Files

A key release policy of Fyskode Toolbox is that **no copyrighted or proprietary assets from J. C. Sprott are distributed with the software**.
1. To inspect this compliance, review the script: [verify_public_release_clean.py](file:///c:/Users/moren/Desktop/Codes/Toolbox%20chaos/scripts/verify_public_release_clean.py) or `docs/distribution_policy.md`.
2. The `Sprott Explorer` tab is strictly a runtime parser. You can local-load a dictionary file (`.DIC`), which is parsed in memory and never copied into the application bundle.

## 7. Numerical Limitations

> [!WARNING]
> All numerical orbits, Lyapunov spectra, and bifurcation sweeps generated by the application are numerical approximations (computational evidence) and do not represent formal mathematical certification of chaotic states or hidden attractors.
