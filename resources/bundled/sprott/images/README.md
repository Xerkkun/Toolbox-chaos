# Sprott image output

This folder stores figures generated by Chaos Toolbox for the Sprott theory
page. Do not add original figures from Sprott's book, site, disk, or software.

Regenerate the public theory figures from the repository root with:

`python assets/sprott/generate_theory_figures.py`

Current generated files:

- `logistic_bifurcation_sprott_theory.png`: logistic-map bifurcation diagram.
- `henon_like_synthetic_sprott_theory.png`: Henon quadratic map generated from
  the equation shown in the theory page.
- `sprott_five_term_flow_theory.png`: original rendering of the five-term 3D
  flow equation cited in Sprott's book.
- `generated/`: additional public figures generated by Chaos Toolbox for
  tutorials and visual-language examples. They are synthetic or newly rendered
  from equations in this repository, not copied from Sprott's book or site.
